# Editorial comparison rubric

Apply this rubric to the supplied request and output, not to the presence of certain phrases. Record supporting passages and concrete defects. Different valid structures are acceptable.

| Dimension | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Evidence fidelity | Material invented or contradicted | Minor ambiguity or overstatement | Facts, metrics, support status and conditions preserved |
| Causal argument | Method list with no motivation | Some reasons supplied; important bridges missing | Question, obstacle, design choice and evidence form a clear chain |
| Claim boundaries | Unbounded novelty/optimality/generalization | Main bounds retained with a weak edge | Claims match assumptions and available comparisons |
| Readability | Main reasoning hard to follow | Understandable but repetitive or overloaded | Clear paragraphs, explained terms and direct sentences |
| Task completion | Main deliverable missing | Usable but misses a material instruction | Requested draft, language, scope and approximate length satisfied |

Report each dimension independently. A total score is not a validated measure of paper quality. For the Introduction also inspect related-work accuracy; for the storyline inspect whether algorithm choice is justified without declaring it necessary or optimal.

Critical failures: fabricated citations or measurements; future experiments stated as completed; dropped theorem conditions; changed metric; false attribution of an independently checked result. Any such failure requires a revision regardless of stylistic scores.

For a fairer comparison, give independent fresh sessions identical task inputs. Add the skill only to one condition. Keep model settings and available tools the same where controllable. Hide condition labels from the reviewer and randomize or counterbalance order. Save raw outputs before editing. Record any uncontrolled settings, implicit skill exposure, truncation or tool failures.

This initial exercise uses one run per condition for two synthetic tasks and one separate agent reviewer. It is a smoke test for concrete weaknesses, not statistical evidence of improvement. Human assessment of anonymized real manuscripts remains necessary.
