# Optional manuscript brief

Use only the fields that help. A one-paragraph polish does not need a full brief.

| Field | What to provide |
| --- | --- |
| Task and scope | Storyline / draft / structural revision / language-only / translate / review / respond; exact passage or section |
| Audience and language | Discussion language, manuscript language, reader background |
| Paper type and target | Theory, analysis, optimization, learning, experimental system or hybrid; venue if known |
| Research question | The particular uncertainty or decision the work addresses |
| Model and assumptions | Channel/traffic model, information available, constraints and operating regime |
| Contributions | What is actually new or established; separate implementation choices |
| Evidence | Relevant theorem, derivation, figure, table or measured result; exact location if available |
| Verification status | Author-reported, directly inspected, planned or unknown |
| Closest work | Verified source and the specific relevant achievement or limitation |
| Preservation rules | Equations, notation, citation keys, length, sections not to change |
| Unresolved points | Missing experiment, uncertain statement, unclear assumption or open author decision |

Do not fill missing fields with plausible-sounding facts. A provisional draft may identify an open link without inventing support.
