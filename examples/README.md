# Usage examples

These prompts can be adapted to a manuscript. They are examples, not required intake forms. For a local edit, supply only the passage and the instruction needed.

## Storyline before prose

```text
Use communications-paper. From the supplied model and results, identify the
central question, existing support and missing reasoning links. Then rewrite
the storyline in Chinese for a communications researcher outside this topic.
Explain why each method is relevant before naming it. Do not force every
implemented module into a separate novelty claim.
```

## Introduction

```text
Use communications-paper to draft a 600-word English Introduction.
Target: TCom; paper type: performance analysis with a design implication.
Use only the attached manuscript and verified literature notes.
Preserve model assumptions and citation keys. Show the specific question left
by the closest works. Mark unverified novelty separately.
```

## Theory abstract

```text
Use communications-paper to write an abstract for this information-theory result.
Keep the theorem's quantifiers, bound direction and parameter regime.
The proof is the evidence; there are no simulations or new coding algorithm.
Do not add them. Distinguish the main result from its interpretation.
```

## Language-only LaTeX

```text
Use communications-paper for language-only polishing of the following LaTeX.
Keep equations, claims, symbols, labels, references and citation keys unchanged.
If a technical assertion is unsupported, flag it after the clean passage and
give any suggested correction separately.
```

## Review response

```text
Use communications-paper to draft point-by-point responses in English.
Inputs: reviewer comments, revised passages and an author action log.
Distinguish completed changes, author-reported actions and undecided work.
Do not invent page numbers, runtime measurements or completed experiments.
```

## Learn from a paper

```text
使用 communications-paper，阅读这篇参考论文，选出最值得学的三个写作片段。
对每个片段标注位置、它回答的读者问题、写法为什么有效、迁移边界。
再用一个不同通信方向的原创例子演示；不要照搬原句或默认更新 Skill。
```
